# Laravel Development

## Objectif

Développer le projet e-commerce avec Laravel en respectant les bonnes pratiques.

## Règles

- Respecter la structure et les conventions Laravel.
- Utiliser Eloquent pour les interactions avec la base de données.
- Utiliser les migrations pour modifier la structure de la base.
- Utiliser les Form Requests pour les validations complexes.
- Garder les Controllers simples.
- Placer la logique métier complexe dans des Services.
- Réutiliser les composants plutôt que dupliquer le code.
- Écrire un code clair, maintenable et sécurisé.

## Sécurité

- Toujours valider les données provenant de l'utilisateur.
- Vérifier les autorisations avant les opérations sensibles.
- Ne jamais exposer les mots de passe ou informations sensibles.
- Utiliser les mécanismes de sécurité fournis par Laravel.

## Méthode de travail

Avant de modifier le code :

1. Comprendre la structure existante.
2. Identifier les fichiers concernés.
3. Proposer une solution simple.
4. Modifier uniquement ce qui est nécessaire.
5. Vérifier que le code fonctionne.
