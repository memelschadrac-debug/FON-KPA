# UI/UX — E-commerce de plats ivoiriens

## Objectif

Concevoir une interface moderne, chaleureuse, appétissante et professionnelle pour une plateforme de commande de plats africains, principalement ivoiriens.

L'interface doit donner envie de découvrir les plats et faciliter la commande.

## Direction visuelle

Le design doit transmettre :

- chaleur
- convivialité
- authenticité ivoirienne
- qualité
- modernité
- confiance

Éviter une interface trop chargée ou folklorique.

L'identité africaine doit être subtile, élégante et moderne.

## Palette de couleurs

L'identité visuelle du site repose principalement sur deux couleurs :

### Couleurs principales

- Marron principal : `#593114`
  - identité
  - titres importants
  - navigation
  - éléments de marque
  - sections fortes

- Orange principal : `#E25F12`
  - boutons principaux
  - appels à l'action
  - prix importants
  - éléments interactifs
  - promotions
  - éléments qui doivent attirer l'attention

### Couleurs complémentaires

Utiliser des couleurs complémentaires chaudes et naturelles afin de créer une identité visuelle harmonieuse avec les couleurs principales.

- Crème : `#FFF8F0`
  - arrière-plans principaux
  - sections légères

- Beige : `#F5E6D3`
  - arrière-plans secondaires
  - zones de séparation

- Marron clair : `#8A5A3B`
  - textes secondaires
  - bordures
  - éléments moins importants

- Jaune doré : `#F4B942`
  - badges
  - promotions
  - étoiles
  - éléments d'accent

- Vert naturel : `#3F6B45`
  - disponibilité
  - confirmation
  - éléments liés aux produits frais
  - messages positifs

- Rouge : `#C0392B`
  - erreurs
  - suppression
  - indisponibilité
  - alertes importantes

- Blanc : `#FFFFFF`
  - cartes
  - zones de contenu
  - contraste

- Texte principal : `#2B211B`

- Texte secondaire : `#6B5B50`

## Règles d'utilisation des couleurs

Les couleurs doivent rester parfaitement synchronisées sur l'ensemble du site.

La palette principale doit respecter cette hiérarchie :

1. `#593114` — identité et structure
2. `#E25F12` — action et conversion
3. `#FFF8F0` — arrière-plan principal
4. `#F5E6D3` — arrière-plan secondaire
5. `#F4B942` — accent
6. `#3F6B45` — états positifs
7. `#C0392B` — erreurs et alertes

Ne pas utiliser toutes les couleurs dans une même section.

Le marron et l'orange doivent rester dominants afin de préserver l'identité de marque.

Les couleurs complémentaires doivent servir à créer de la profondeur et de la hiérarchie visuelle, et non concurrencer les couleurs principales.

Le design doit être chaleureux, premium, appétissant et moderne.

Éviter les couleurs trop saturées ou les combinaisons qui donnent une apparence criarde.

Les boutons principaux doivent utiliser `#E25F12` avec un texte suffisamment contrasté.

Les éléments de marque et les titres importants peuvent utiliser `#593114`.

Les arrière-plans doivent principalement utiliser `#FFF8F0`, `#FFFFFF` et `#F5E6D3`.

L'ensemble de la palette doit donner une impression de cuisine ivoirienne authentique, chaleureuse et contemporaine.

## Typographie

Utiliser une typographie moderne et lisible.

La hiérarchie doit être claire :

- titre principal
- titre de section
- nom du plat
- description
- prix
- informations secondaires

Les textes doivent rester faciles à lire sur mobile.

## Page d'accueil

La page d'accueil doit présenter :

1. Hero section avec une image appétissante.
2. Message clair sur la cuisine proposée.
3. Bouton principal pour commander.
4. Catégories de plats.
5. Plats populaires.
6. Plats du jour si disponibles.
7. Avantages du service.
8. Section livraison.
9. Témoignages ou avis clients.
10. Footer.

Le client doit comprendre rapidement ce que propose le site.

## Cartes de plats

Chaque carte doit présenter clairement :

- image du plat
- nom
- courte description
- prix
- disponibilité
- bouton d'action

Les images doivent être mises en valeur.

Utiliser des proportions cohérentes pour les images.

Éviter les cartes excessivement chargées.

## Page détail d'un plat

Présenter :

- grande image
- nom
- description
- prix
- options disponibles
- suppléments
- quantité
- bouton "Ajouter au panier"

Les options doivent être faciles à comprendre.

## Panier

Le panier doit être clair et rapide à utiliser.

Afficher :

- image du plat
- nom
- options
- quantité
- prix unitaire
- sous-total
- frais éventuels
- total
- bouton de commande

Permettre de modifier facilement les quantités.

## Checkout

Le checkout doit être simple et organisé.

Regrouper les informations en étapes logiques :

1. Informations client.
2. Livraison ou retrait.
3. Adresse si nécessaire.
4. Moyen de paiement.
5. Récapitulatif.
6. Confirmation.

Éviter les formulaires inutilement longs.

## Responsive design

L'application doit être conçue en priorité pour mobile.

Elle doit fonctionner correctement sur :

- smartphone
- tablette
- ordinateur portable
- écran desktop

Les boutons doivent être suffisamment grands pour être utilisés au toucher.

Les menus et formulaires doivent rester faciles à utiliser sur petit écran.

## UX

Toujours privilégier :

- simplicité
- lisibilité
- rapidité
- cohérence
- feedback utilisateur

Après une action importante, fournir un retour visuel clair.

Exemples :

- produit ajouté au panier
- commande confirmée
- paiement réussi
- erreur de validation
- produit indisponible

## Accessibilité

Respecter les principes fondamentaux d'accessibilité :

- contraste suffisant
- labels explicites
- navigation clavier
- textes lisibles
- attributs alt pour les images importantes
- messages d'erreur compréhensibles

## Tailwind CSS

Utiliser Tailwind CSS de manière cohérente.

Éviter :

- les classes excessivement longues répétées partout
- les styles incohérents
- les valeurs arbitraires sans raison
- la duplication inutile

Créer des composants réutilisables lorsque cela améliore la maintenabilité.

## Principes

Le design doit être :

- moderne
- responsive
- accessible
- cohérent
- performant
- orienté conversion

Ne jamais sacrifier l'expérience utilisateur pour ajouter des éléments visuels inutiles.

Avant de créer une nouvelle interface, vérifier les composants existants et les réutiliser lorsque possible.
